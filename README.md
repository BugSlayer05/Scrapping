# LDPlayer-archive

Password-protected multi-volume 7z archives of an LDPlayer install.

- Format: `ldplayer.7z.001` … (80 MB volumes)
- Extract with 7-Zip starting from `.001`
- Password is shared separately (not stored here)

Assets are attached to the [v1 release](https://github.com/BugSlayer05/LDPlayer-archive/releases/tag/v1).
